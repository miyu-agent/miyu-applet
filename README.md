# Miyu system tray (miyu-applet)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

The Miyu system tray makes Miyu work out of the box: it is ready to use once installed, and you do not need to open a terminal. After installing, open `Miyu` from the application menu; it opens Miyu's web UI in your browser and stays in the system tray itself (the menu bar on macOS). From the tray you can see whether Miyu is running, stop, start and restart Miyu, open the web UI and the settings, set Miyu to start at login, and open the folder that holds the logs. Even after the browser is closed, it shows system notifications such as `Done` and `Waiting for your approval`, and clicking a notification opens that session; clicking `Quit Miyu` shuts down the core as well.

- This repository is the tray program `miyu-applet`: it has no window of its own, and its interface is entirely in the web UI. The web UI lives in [miyu-agent/miyu-web](https://github.com/miyu-agent/miyu-web) and the core in [miyu-agent/miyu](https://github.com/miyu-agent/miyu); the installers bundle all three together.
- The tray uses [`tray-icon`](https://github.com/tauri-apps/tray-icon) and [`tao`](https://github.com/tauri-apps/tao) (Tauri's own tray and event loop), with one codebase for all three platforms and no web view.
- It supports Linux, macOS (M-series chips) and Windows. On Linux it needs GTK 3, and the tray uses the StatusNotifierItem protocol (built into desktops and bars such as KDE and waybar; on GNOME, the tray only shows up after you install the AppIndicator extension).
- The terminal UI is not in this repository; install [miyu-agent/miyu-tui](https://github.com/miyu-agent/miyu-tui) separately.

How to install (deb and rpm on Linux, dmg on macOS, msi on Windows, plus AUR and Homebrew) is described in [Installing, upgrading and uninstalling](https://github.com/miyu-agent/miyu/blob/main/docs/en/guide/install.md); how to use the menu, notifications, starting at login and LAN access is described in [System tray](https://github.com/miyu-agent/miyu/blob/main/docs/en/guide/heads/applet.md).

Before you change the code in this repository, read [`docs/blueprint/app.md`](docs/blueprint/app.md) first.
