## AP-24：`miyu-applet --version`、`--help` 印完就退

状态：已完成（2026-11-28，本机门禁和伪终端实测见「结果」）。Windows 上从命令提示符里跑的样子没有测过，见「要人定的」。

### 目的

rc.5 装机验收时跑了 `miyu-applet --version`：托盘不认这个参数，照常起了托盘（还冒出 atspi 的警告）。托盘首次起来会自己用浏览器打开网页界面，误起一次就弹到桌面上。别的 Miyu 程序（`miyu`、`miyu tui`）都是印了版本就退，托盘也要这样。

### 图纸改哪几节

- `app.md` 第 1 条「从应用菜单打开」：多一款「只问一句的」。

### 做法

1. `src/usage.rs`：读参数，哪里有 `-h`、`--help` 都是帮助（两样都写了的也是帮助，同网页），不然有 `-V`、`--version` 的是版本；`--open`、`--home` 后面那一个是值，不算。版本印一行 `miyu-applet <版本>`（同核心 `miyu --version`：程序名加版本），帮助印帮助页，都在标准输出上，退出码 0。
2. 帮助页照核心、网页的帮助页写（`用法：` 一行、说明、`选项：`），中文、英文、日文三份放在 `resources/help/`，语言照托盘菜单的挑。只写 `-h`、`-V` 两样：`--autostart`、`--open`、`--home` 是启动项、通知的网址给的，不写进去（同网页不写 `serve`、`forget`）。
3. `main` 第一件事就照它办，在调堆参数、找数据根、单实例、建事件循环和托盘、连核心之前。
4. 别的参数照旧：不认识的当没写，起托盘。

### 不做什么

- 不认识的参数不报错：原来就是当没写，改成报错要先问。
- Windows 的正式版不接父进程的控制台（要 `unsafe` 调系统接口，仓库不许）。

### 验收

- 单元测试 `usage::tests`：读参数的各种写法、版本那一行、三份帮助页都有两样选项。
- 端到端 `tests/early_exit.rs`：环境清空、只给一个空沙箱（家目录、`XDG_STATE_HOME`、`XDG_RUNTIME_DIR`、`LOCALAPPDATA`、`MIYU_HOME` 都指进去，没有显示、没有会话总线），跑编出来的程序：`--version`、`-V` 印 `miyu-applet <版本>`，`--help`、`-h` 印帮助（Linux 上照 `LC_ALL` 分别是中文、英文、日文），退出码 0、标准错误是空的、10 秒内退出，跑完沙箱还是空的（真起了托盘会建托盘自己的目录）。
- 伪终端里跑编好的程序，`timeout 10` 包着，看输出和退出码，跑完 `ps` 查没有留下的 `miyu-applet`。

### 结果

- 本机（Linux）：`cargo fmt --check`、`cargo clippy --workspace --all-targets --locked -- -D warnings`、`cargo test --workspace --locked`（托盘 135 条、端到端 3 条、xtask 21 条）、`cargo doc`（`-D warnings`）、行数、`cargo xtask licenses`、`cargo xtask privacy`、打包的单元测试（3 条）都过。
- 端到端的三条在 `main` 不接这一步时（`usage::early` 的结果扔掉）全红：程序照常起托盘，清空的环境里起不来 GTK、退出码不是 0。
- 伪终端里跑编好的程序（`timeout 10`，数据根、`XDG_STATE_HOME` 指到空目录）：`--version`、`-V` 印 `miyu-applet 2026.11.0`，`--help`、`-h` 印帮助页，退出码都是 0；`LANGUAGE` 设成日文、英文的分别印日文、英文那一份（`sys-locale` 先看 `LANGUAGE` 再看 `LC_ALL`，同托盘菜单）。跑完没有留下 `miyu-applet` 进程，两个目录都还是空的。

### 要人定的

- Windows 正式版从命令提示符直接跑 `miyu-applet.exe --version` 看不到输出（图形子系统没有控制台），要不要做。
- 不认识的参数要不要像 `miyu tui` 那样报用法、退出码 2：现在照旧起托盘。
